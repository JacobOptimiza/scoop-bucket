# Scoop bucket for DevNav

Official Scoop bucket for [DevNav](https://github.com/JacobOptimiza/dev-nav),
a native workspace navigator for PowerShell 7 on Windows.

## Install

```powershell
scoop bucket add jacoboptimiza https://github.com/JacobOptimiza/scoop-bucket
scoop install jacoboptimiza/devnav
```

## Update

```powershell
scoop update devnav
```

## Uninstall

```powershell
scoop uninstall devnav
```
